## Company brain

Before starting work, read `~/brains/neutral/map.md` in the [company brain](https://github.com/neutral-trade/cerebro). If the local copy is unavailable, read the [map on GitHub](https://github.com/neutral-trade/cerebro/blob/main/map.md).

When the code and brain disagree, the code wins. If something you need is missing or wrong, open an [issue in Cerebro](https://github.com/neutral-trade/cerebro/issues) labelled `flag`. Say what you needed, what you found and link to the evidence.

Fill in the Learned section on every PR. “None” is a full answer.
